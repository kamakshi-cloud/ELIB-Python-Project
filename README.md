\# 📚 E-Library Management System



A web-based \*\*E-Library Management System\*\* developed using \*\*Python and Flask\*\*. The application provides a simple platform for managing books, users, and book requests through a web interface.



\## 🚀 Features



\* User registration and login

\* User authentication using Flask sessions

\* Add new books

\* Edit existing book details

\* View available books

\* Manage book requests

\* Dashboard for library management

\* SQLite database for storing application data

\* Simple and responsive web interface



\## 🛠️ Technologies Used



\* \*\*Python\*\*

\* \*\*Flask\*\*

\* \*\*SQLite\*\*

\* \*\*HTML5\*\*

\* \*\*CSS3\*\*

\* \*\*Jinja2\*\*

\## ⚙️ Installation



\### 1. Clone the repository



```bash

git clone https://github.com/kamakshi-cloud/ELIB-Python-Project.git

```



\### 2. Open the project folder



```bash

cd ELIB-Python-Project

```



\### 3. Install Flask



```bash

python -m pip install flask

```



\### 4. Run the application



```bash

python app.py

```



\### 5. Open in your browser



Open:



```text

http://127.0.0.1:5000

```



\## 🎯 Project Objective



The objective of this project is to develop a simple digital library system that allows users to interact with library resources through a web application. It demonstrates the use of \*\*Python, Flask, web development, database management, authentication, and CRUD operations\*\*.
